Тестирование класса BooksCollector

Описание проекта
Автоматизированные тесты для класса "Bookscollector", который:
- Управляет коллекцией книг
- Назначает жанры книгам
- Работает с избранными книгами

Покрытые тестами методы
Добавление книг
- Проверка добавления валидных названий
- Блокировка пустых названий
- Ограничение длины названия (40 символов)
- Защита от дубликатов

Работа с жанрами
- Установка разрешенных жанров
- Блокировка недопустимых жанров
- Получение книг по жанру
- Фильтрация детских книг (без возрастных ограничений)


Фикстуры
new_collector - чистый экземпляр
collector_with_books - с тестовыми книгами
collector_with_favorites - с избранными книгами
